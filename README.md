# Moov - Movement Break Reminder

Moov is a macOS menu bar app that reminds you to move and stretch regularly while working.

## Documentation

- Setup and build instructions: `docs/SETUP.md`
- Feature guide: `docs/FEATURES.md`
- Architecture details: `docs/ARCHITECTURE.md`
- Development notes: `docs/CHANGELOG.md`

## Features

- Menu bar app (no dock icon)
- Configurable break intervals
- Full-screen semi-transparent overlay
- Snooze actions (5/10 min)
- Activity suggestions
- Quiet hours support
- Presentation mode toggle
- Basic statistics tracking
- Keyboard shortcuts

## Usage

### Menu Bar
Click the walking figure icon in the menu bar to access:
- **Take Break Now** - manually trigger a break
- **Pause for X hours** - temporarily stop reminders
- **Presentation Mode** - prevent interruptions during meetings/demos
- **Settings** - configure intervals, quiet hours, activities
- **Statistics** - view break history and compliance

### During a Break
- **Space/Enter** - "I moved!" (dismiss and reset)
- **1** - Snooze 5 minutes
- **2** - Snooze 10 minutes
- **Esc** - Quick snooze (5 minutes)

### Settings Tabs
- **General** - break interval, sound notifications
- **Schedule** - quiet hours configuration
- **Activities** - activity suggestion toggle
- **About** - app information
